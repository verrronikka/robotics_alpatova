# Использование ИИ

## PR01

- Использован ИИ: да.
- Инструмент и модель: Codex desktop, GPT-6 Luna.
- Помощь: инструкции по установке ROS 2 Jazzy и turtlesim, объяснение команд ROS 2 и доменов, помощь с разбором вывода и оформлением отчёта.
- Проверка: команды запуска и наблюдения выполнены пользователем в Ubuntu 24.04.3 под WSL2. Ноды, топики, тип позы, частота, разрыв связи в домене 17 и восстановление в домене 16 проверены по фактическому выводу терминала.
- Код собственной ROS-ноды для этой работы не создавался.

## PR02

- Использован ИИ: да; ai_used=true в отчёте.
- Инструмент: Codex desktop.
- Модель текущей сессии: GPT-6.1 Sol (gpt-6.1-sol).
- Затронутые компоненты: пакет turtle_bringup, launch/sim.launch.py, setup.py, package.xml, README.md, workflow GitHub Actions, файлы evidence/pr02 и декларация ИИ.
- Характер помощи: пошаговые команды, подготовка launch-файла и метаданных, объяснение сборки и установки, план эксперимента с именем топика, разбор вывода, подготовка документации и CI.
- Источники: условие ПР02, предоставленные лекции, официальная документация ROS 2 и GitHub Actions.
- Проверка: пользователь лично выполнял команды в Ubuntu 24.04.3 под WSL2. По выводу терминала проверены первая и итоговая сборки, синтаксис launch-файла, обнаружение пакета, появление и исчезновение ноды при запуске и остановке launch, типы топиков, изменение позы после команды, отсутствие движения при ошибочном имени и восстановление движения после исправления.
- Дополнительное подтверждение: пользователь наблюдал движение черепашки и её остановку. Логи сохранены через tee.
- Собственная ROS-нода с callback для этой работы не создавалась.

Секреты и личные данные в декларацию не включены.
